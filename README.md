# Skillora 🚀

### Student Freelance Marketplace

Skillora is a student-focused freelance marketplace designed to connect
college students with clients who need affordable digital services.

## ✨ Features

- Student and client registration
- College email verification with OTP
- Student profiles and skill management
- Job posting and job applications
- Skill-based candidate matching
- Student and client dashboards
- Application status tracking
- Reviews and ratings
- Role-based authentication

## 🛠️ Tech Stack

- React + Vite
- React Router
- Node.js + Express
- PostgreSQL
- Axios
- JWT Authentication

## 🎯 Objective

Skillora helps college students gain real-world experience,
build their portfolios, showcase their skills, and earn through
freelance projects.

## 🚀 Future Improvements

- Real email/SMS OTP delivery
- AI-powered skill analysis
- Team formation and multi-role project matching
- Online payments
- Notifications

## 👨‍💻 Project

Skillora is developed as a college project to bridge the gap
between student skills and real-world freelance opportunities.
